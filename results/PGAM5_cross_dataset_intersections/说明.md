# 三份上调候选列表的交集

按 gene symbol 精确匹配，不做别名转换。三份列表均使用 FDR <0.05、log2FC >=1、至少一组检出率 >=10%，排除定义分组的 PGAM5。

GSE125449 (331) 与 GSE151530 (740)：26 个；GSE125449 与 GSE149614 (512)：13 个；GSE151530 与 GSE149614：76 个。

三者共有 4 个：CENPH、GINS2、NCKAP1、OAF。各交集表保留每个数据集的 log2FC、FDR 及两组检出率；含 GSE125449 的表另保留其补充 Fisher 精确检出率 FDR。

这是常规合并细胞 Wilcoxon 上调候选的交集。GSE125449 仅 4 个 PGAM5 检出 TAM，其候选及本次四个三者共同基因均未通过补充精确检出率检验 FDR <0.05。该补充检查与表达秩检验并非同一种检验。

GSE125449 的全部 298 个保留细胞标识（论文样本号+barcode core）均可在 GSE151530 找到，因此二者不是独立验证证据。没有核实原始表达矩阵逐基因完全相等，也没有将标识重叠解释为完整矩阵一致。

巨噬细胞定义也不完全相同：GSE125449/GSE151530 使用原注释 TAM，GSE149614 使用标志定义的巨噬细胞富集聚类。四个共同基因是进一步研究的探索性候选，不能称为三独立队列验证的 signature。

原始结果位于同仓库 results/PGAM5_HCC、results/GSE149614_PGAM5_primaryT、results/GSE125449_HCC_PGAM5。
