# GSE151530：按GSE202642模板补充PGAM5表达与亚群名称

沿用此前GSE151530 HCC分层聚类中的3,095个巨噬富集细胞、16个探索性RNA群（M0–M15）、28个样本和21个患者编号代理。153个细胞检出PGAM5（4.94%）。本轮不重新聚类或计算UMAP。

直接沿用GSE202642原绘图脚本的字体、画布、标题和副标题位置、黄–橙–红色阶、两侧标志基因＋RNA程序名称与引线、底部水平色条及图注。图中完整标注16个名称；M编号在统计表中对应。为适应16群，左右各8个标签。未把GSE202642的亚群名称或几何形状复制到本数据。

群均值图每个点着色为其所在群的**逐细胞log1p(CP10k)的算术平均值，包含全部零值**；不是log1p(群平均CP10k)。群平均为0的M12、M15显示灰色。群均值色阶0–0.096893；逐细胞色阶0–2.301057，各图按自己的完整范围缩放，因此跨数据集不能直接凭颜色比较数值。

CP10k = PGAM5原始计数 / 该细胞完整转录组原始总计数 × 10,000。零值均保留；逐细胞图灰色表示原始计数0。不做插补、平滑、裁剪或强制聚群。

## 复现与核验

```bash
python -m pip install -r requirements.txt
python plot_expression.py
```

包内轻量输入可直接重绘，无需原始全基因矩阵。首次提取输入可使用相邻的`GSE151530_HCC_hierarchical_clustering`目录中的marker h5ad和坐标表。输入提取时逐细胞核对PGAM5原始计数和保存坐标；归一化使用完整文库总量，不能使用marker子矩阵的行和。

`verification.json`记录统计与原分析逐项一致、细胞和群总数一致、加权群均值等于总体均值、输入未修改、所有标签位于画布内等核验。PNG/PDF已检查无文字裁切，16个名称和对应引线可见。`source_provenance.json`记录源文件SHA256；`manifest.json`与`archive_verification.json`记录下载包完整性。
