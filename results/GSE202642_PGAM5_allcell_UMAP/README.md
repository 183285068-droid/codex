## 计算与解释

CP10k = 单细胞PGAM5原始计数 / 该细胞原始全转录组总计数 × 10,000。群均值包含全部零值；单细胞UMAP颜色使用log1p(CP10k)，自然对数，完整范围不截断。检出率定义为原始PGAM5计数>0的细胞比例。未检出不解释为蛋白阴性。群平均表达UMAP把群均值赋予群内所有点，表示群水平统计量；逐细胞图显示真实单细胞异质性。

这是描述性比较，未计算组间显著性p值。提供每患者×亚群统计以检查患者构成。C20约98%的细胞来自同一患者，均值排序可能受患者组成和低计数影响；C10为增殖混合谱系群，C19为巨噬/T-NK混合RNA群，C1、C15保留限定性注释。CP10k是相对RNA表达量，不是绝对RNA分子数或组织浸润比例。使用全库大小归一化，未另外回归测序深度。

## 文件与复现

- PGAM5_expression_UMAP.png/pdf：逐细胞表达及检出状态。
- PGAM5_cluster_mean_and_detection_UMAP.png/pdf：群平均表达及检出率。
- PGAM5_cluster_comparison.png/pdf：全部21群排序比较。
- PGAM5_by_cluster.csv：完整群统计；PGAM5_by_cluster_patient.csv：患者分层统计。
- PGAM5_cell_expression_and_UMAP.csv.gz：逐细胞表达与原坐标。
- inputs/：原始标签、坐标和便携原始计数快照。
- validation.json：来源哈希和分析检查；SHA256SUMS：包内文件哈希。

解压后在该目录运行：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python analyze_plot.py
```

脚本重新从稀疏原始计数提取PGAM5，以全转录组总计数归一化并复现所有统计和图；不需要重新运行聚类。包装前独立核对输出坐标与输入坐标完全一致、所有21群均值和检出数，以及输入文件哈希。PNG和PDF均已人工检查。
