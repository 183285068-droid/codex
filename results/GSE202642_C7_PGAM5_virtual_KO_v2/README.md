# C7增殖型巨噬细胞PGAM5虚拟敲除：重复稳定性评估

## 结论

固定此前15群版本GSE202642 C7（MKI67/TOP2A）的403个细胞，7个患者标签，79个PGAM5 RNA检出细胞，包含所有零值；固定上次同一套1,501建模基因。两套方案各5个随机种子，完成10次新的scTenifoldKnk模型运行及10次相同WT网络无敲除对照。

增加网络重采样并提高分解阶数的方案**仍未通过本轮预设的整体稳定标准**。其中21个非靶基因在至少4/5次运行中模型FDR<0.05，属于该参数方案下的重复候选，不等于已验证的PGAM5因果调控靶点。

## 预设标准与方法

开始本轮计算前在protocol.json固定：所有种子两两非靶基因扰动排序Spearman rho≥0.8、前50候选Jaccard≥0.5、所有无敲除对照0个显著、张量分解全部收敛。候选层面另要求至少4/5次模型FDR<0.05。完整模型结果均保留，没有从不同种子中只选显著最多者；不将median_model_q视为合并p值。

- precision_only：保持上次10个网络、rank=5、稀疏化q=0.95，仅把张量归一化后的舍入精度从1位增加为6位，tol=1e-5、最大1,000轮。
- ensemble：30个网络、rank=10、q=0.95、6位精度、tol=1e-7、最大2,000轮。
- 每网络有放回抽取300个细胞，PC回归3成分；网络输入为CPM，分母沿用原始全库总计数。没有因增加精度而更改细胞、基因、零值或归一化分母。
- 直接调用scTenifoldpy 0.5.1的网络构建、CP张量分解、流形对齐和差异调控函数。其默认张量管线本身会归一化、舍入、转置；代码明确复现这些操作并提高舍入精度。PGAM5行置零，其他网络行保持不变；对齐30维。
- 保存每次CP分解是否收敛、迭代次数和残差轨迹。此处为残差变化收敛，不能证明优化达到全局最优。
- 每次模型用相同WT网络对齐作为无敲除对照，显著基因均为0。

## 解释范围

本轮评估的是同一数据、不同种子的计算可重复性，不是跨患者独立验证或实验敲除。没有额外回归患者、测序深度或细胞周期，也没有改变目标403细胞的构成。单细胞重采样不等于独立患者重复；C7中一位患者占197/403细胞，患者构成可能影响共表达网络。

网络位移Distance无方向；FC为位移平方/背景期望，不是表达fold change。模型卡方p值和BH q值不是实验KO的差异表达检验。即使重复候选增多，仍不能判定敲除后增殖或抗肿瘤免疫增强/减弱。靶点PGAM5保留在完整结果中，但其被强制干预的显著性不计入下游证据。

程序分析使用此前明确列出的免疫程序以及热休克/即时反应集合，均保留PGAM5成员；对非靶点重复候选进行探索性单侧Fisher富集，背景为实际建模的1,500个非靶基因，14个程序BH校正。不是完整GO/KEGG分析，不用PGAM5强制敲除信号驱动程序显著性。

## 文件与复现

- stability_summary.csv、pairwise_stability.csv：整体稳定性及所有两两比较。
- run_metrics.csv：10次运行候选数、PGAM5出边、分解收敛和耗时。
- ensemble_recurrent_candidates.csv：至少4/5次显著候选。
- *_consensus.csv：全部非靶基因的显著频率、描述性中位q及排序。
- *_stability.png/pdf：重复频率及排序一致性图。
- precision_only/、ensemble/：各种子的完整差异调控、WT网络、分解残差和无敲除对照。
- *_recurrent_program_enrichment.csv：重复候选程序探索。
- inputs/：固定原始基因×细胞计数、原始全库总计数、元数据及程序定义。特征矩阵不含完整转录组，不可用该子集求和重新归一化。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
OPENBLAS_NUM_THREADS=4 python run.py
OPENBLAS_NUM_THREADS=4 python audit.py
```

脚本默认复用已有metrics.json和无敲除输出。完整从头复现请在新目录复制inputs/、run.py、audit.py、requirements.txt后运行，无需原始GEO大矩阵。独立核对细胞顺序、所有403个PGAM5计数、1,501基因/完整输出数量、网络及q值有限、10次对照、文件哈希和ZIP CRC。平台及底层特征求解器可能导致微小浮点差异。
