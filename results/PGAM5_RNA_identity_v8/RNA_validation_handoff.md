# RNA层面的验证与交接

本轮目标是“巨噬细胞身份确认后PGAM5原始RNA计数>0”的检出群。按用户要求，蛋白检测和跨队列复现不作为条件。当前RNA注释已提供；下列工作用于检验它能否成为可定量的bulk参考。

## 可立即使用的注释

使用`GSE*_RNA_annotation.csv.gz`精确回填原对象。保留RNA检出/未检出、既往谱系、谱系标志共检出证据及候选模块分数的独立字段。零计数保持未检出；模块高分没有改变它。一个基因在候选参考中出现，也不自动证明它是PGAM5状态的特异标志。

本轮395基因×20组分参考包含PGAM5、巨噬标志和充分竞争组分。主方案不设置FDR/log2FC硬阈值。内部混合恢复仍失败，因此当前不能把它作为可靠TCGA细胞比例工具。

## RNA身份记录

`RNA_sample_template.tsv`记录患者、样本、探索/验证划分、历史模型使用、RNA平台及冻结定义。`RNA_identity_template.tsv`记录精确细胞ID、谱系、PGAM5原始计数及可用的独立RNA检测结果。

原始RNA检出定义不要求额外正交实验。若有独立RNA检测、原位RNA或冻结规则后新收集的RNA数据，可以补充其方法、证据ID和目标标签，评价注释与独立RNA观测的吻合；没有此类结果时`independent_RNA_truth_available=False`，不编造结果。未观测的真值字段只作占位，不能按阴性计入吻合度。单患者多个组织块或技术重复不能计为多个患者。

## 已知比例的RNA/bulk混合验证

若要评价真实细胞比例恢复，需记录实际加入的目标细胞、其他巨噬、单核、DC、肿瘤及其他细胞数量与总数，另保存实际bulk测量。推荐预先固定0、0.5%、1%、2%、5%目标比例，并包含目标为0的髓系和PGAM5检出非巨噬竞争背景。至少3个独立患者；技术重复用于估计误差，不增加患者数。

若按RNA状态进行富集/分选，需先确定身份测量、RNA保存和bulk建库流程兼容，目标数量与纯度可独立记录。当前没有执行此类物理实验，也没有相关实测输入。

记录目标细胞比例与RNA贡献比例的区别、每群RNA量/捕获影响及bulk平台单位。用同一bulk平台测量已知输入的混合物，可以检验与校准参考的量纲；不能直接把观测文库RNA贡献当作细胞比例。保留校准原数据，并在模板中填写其证据ID。

## 工具与判定

填写三张TSV模板后运行：

```bash
python validate_RNA_inputs.py \
  --samples RNA_sample_template.tsv \
  --RNA-identity RNA_identity_template.tsv \
  --mixtures RNA_physical_mixture_template.tsv \
  --output-dir RNA_validation_results
```

工具核对细胞数、总数、真实比例、重复ID、患者划分泄漏，并按患者/剂量平均技术重复后计算MAE、相关性及目标缺失P95。沿用项目操作门槛MAE≤1百分点、r≥0.7、零目标P95≤0.5%，并检查剂量覆盖及零目标竞争情形。这些是本项目预设门槛，不是所有疾病和平台通用标准。

模板目前为空，结果为`NOT_RUN_REQUIRED_RNA_INPUTS_MISSING`，不解释为通过。`computational_replay/`来自真实保存的历史计算混合物，明确标记非物理实验、历史已使用、独立RNA真值不可用；其目的仅是证明工具可以处理实际计算输入。

即使数值门槛通过，证据ID、物理混合声明及单位校准仍需核查原记录；工具不会自动认证TCGA用途。当前新参考的数值门槛已经失败，因此继续推算TCGA时只能报告探索性系数。
