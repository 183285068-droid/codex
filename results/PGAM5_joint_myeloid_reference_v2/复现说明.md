# 复现入口

1. 从GEO取得GSE151530、GSE149614、GSE189903官方矩阵和元数据，按来源哈希核对。151530限HCC，149614限T结尾原发肿瘤，189903限HCC core+border。
2. 151530/149614全细胞QC h5ad由仓库`results/PGAM5_reference_GSE151530_GSE149614_validation/prepare_references.py`生成。源细胞注释、旧巨噬细胞群判定资料位于该目录及此前数据集结果目录。QC≥500基因，MT<20%。环境版本记录在environment_versions.json。
3. 设置PGAM5_SOURCE_ROOT为原始资料根目录（其下为GSE189903等目录），PGAM5_PREVIOUS_REFERENCE_ROOT为151530/149614全细胞QC h5ad所在目录。核心脚本默认路径为本云工作区路径，需在复现机器设置变量。所有输出写入脚本所在目录。
4. 依次运行`python reannotate_myeloid.py GSE151530`、`python reannotate_myeloid.py GSE149614`、`python reannotate_myeloid.py GSE189903`。脚本已内置修正版Mixed_APC规则；fix_mixed_annotation.py仅用于记录本次缓存注释修正过程，无需在重新聚类后额外运行。
5. 运行`python train_joint_reference.py`、`python audit_implementation.py`、`python build_deliverables.py`。CPU线程设置可使用OPENBLAS_NUM_THREADS=1；Scanpy的缓存路径需有写权限。

预设性能门槛和未通过项原样保留。只要未通过，输出矩阵为研究验证参考，不能解释为已验证的TCGA丰度算法。大型原始矩阵和QC h5ad不随包分发。
