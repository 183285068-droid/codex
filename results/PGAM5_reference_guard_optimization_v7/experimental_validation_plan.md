# 需要独立完成的生物学身份与真实混合物验证

本文件是待实施的实验设计和数据交接规范。本轮没有执行蛋白检测、物理分选或真实bulk混合实验；不能把计算机抽样混合物写成这些实验的替代。

## 1. 先检验是否确有一个可以命名的目标群

建议起步收集两个互不重叠的HCC患者集合，各约10位用于探索和锁定后验证；这是可执行的起步规模，不是效能保证，最终数量须按预实验的患者间变异、阳性率及允许误差确定。以患者为独立重复，记录肿瘤部位、处理时长、批次及MVI；当前范围保留不按MVI筛选的HCC。不得把一个患者的多块组织或多个技术重复计为独立患者。

在同一细胞或可空间对应的细胞中联合确认巨噬谱系与PGAM5：可用多重免疫成像或RNA原位结合蛋白，采用至少两个互补巨噬标记，例如CD68和CD163，并结合LST1/CSF1R等RNA及组织形态。同步区分单核、DC、肿瘤细胞和细胞混合/双细胞；单一CD68信号不足以排除所有其他髓系细胞。记录MKI67增殖及即刻早期/应激表达，不把高增殖或解离反应直接命名为PGAM5状态。

PGAM5为胞内蛋白，检测抗体必须在相同组织/平台上验证特异性和动态范围；使用阴性、背景和适当的阳性对照，能做时纳入敲低/敲除对照。阈值需由这些对照及探索集合确定后锁定。不能直接用scRNA原始计数1、2或3作为蛋白阳性的阈值。

同时检查目标是否呈可重复离散群，还是巨噬细胞内的连续表达梯度。如果只是连续梯度，应输出“PGAM5相关表达状态分数”，不要人为二分后宣称一个稳定细胞亚群。protein/RNA不一致应如实记录，不用蛋白标签覆盖原RNA观测字段。

## 2. 用独立身份真值重建单细胞注释及参考

将上述身份真值与单细胞表达精确连接；参考需包括目标巨噬细胞、其他巨噬细胞、单核、cDC/pDC、其他免疫、内皮/CAF、肿瘤/肝细胞和未知组分。PGAM5可保留为锚点，但需要其他独立于PGAM5定义的、跨患者一致的状态特征。

可沿用用户原有细胞汇总差异筛选规则FDR<0.05、log2FC≥1；另检验患者方向一致性和对竞争细胞的特异性，不做患者配对DE。周期、应激、核糖体/线粒体和仅谱系身份基因不能单独充当状态特异性证据。特征、目标阈值和算法在探索集合固定，独立验证集合不参与选择。

细胞数不足、只有PGAM5本身区分、独立验证没有方向一致性或目标在竞争群中也高表达，均应停止“可用丰度工具”的结论；可以保留RNA状态研究。

## 3. 构建真正已知比例的混合物

先通过预实验确定胞内蛋白检测、固定/透化或其他身份测定方式是否与RNA保存和后续表达测量兼容。不能假定普通活细胞表面分选能直接按胞内PGAM5可靠分选；需要实验平台确认适用流程或其他独立身份方法。

至少在多个独立验证患者中配置以下物理混合情形：

| 维度 | 预设情形 | 要解决的问题 |
|---|---|---|
| 目标比例 | 0、0.5%、1%、2%、5% | 零目标假阳性、低剂量检出及恢复 |
| 总巨噬细胞 | 10%、25%、50% | 状态比例与总巨噬细胞含量是否混淆 |
| 零目标髓系竞争 | 增加其他巨噬、单核及DC/pDC | 防止竞争群被解释为目标 |
| 零目标PGAM5背景 | PGAM5高表达的非巨噬细胞、肿瘤与增殖群 | 检验PGAM5谱系非特异性 |
| 技术重复 | 每个条件至少3个独立制备/建库重复 | 测量实验误差，不计为独立患者 |

每份混合物记录实际加入细胞数量、分选纯度和存活/固定情况，并测定总RNA及平台。低比例需保证实际目标数量足够，例如总细胞20,000时0.5%=100个目标；实际输入量和建库兼容性需预实验决定。不同患者分别制备，不仅将同一个患者重复抽样。

目标细胞比例真值为实际目标细胞数/总细胞数，另记录RNA贡献比例。测定每群的RNA量与捕获差异，校准二者转换。纯细胞和混合bulk使用相同基因注释及长度/平台归一化；TCGA的read counts、CPM或TPM不能未经验证互换。PGAM5 RNA约束只适用于查询与参考处于可比表达单位时。

## 4. 判定和交接

保持现有计算门槛：独立患者覆盖、标准MAE≤1百分点、r≥0.7、所有零目标压力情形估计P95≤0.5%。另逐剂量报告低比例检出、偏差和总巨噬细胞恢复，避免输出全部为0却通过零目标测试。应预先明确检出阈值和期望灵敏度，不在验证集合反复挑选阈值。

只有独立身份、参考特异性、真实混合物恢复、平台及细胞RNA比例校准均通过后，才将输出命名为TCGA-LIHC目标细胞丰度，再做分期或生存关联。OS/PFI关联显著不能替代这些验证。

配套模板是`sample_validation_template.tsv`、`cell_identity_template.tsv`和`physical_mixture_template.tsv`；均仅含字段表头，未填充或伪造患者/实验结果。原始影像、背景对照、表达矩阵、样本映射和处理记录需保留以支持复核。
